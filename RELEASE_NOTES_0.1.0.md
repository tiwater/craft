# CRAFT v0.1.0 — research baseline

Initial public release of Code-based Robotic Automation for Fast-Food Tasks.

Includes a restricted policy interpreter, frozen policy bundles, durable command
intent/receipt journal, host-bound completion verification, explicit Codex/API
generation transports, and coffee/bagel/combo software contract fixtures.

The literature registry contains 22 primary-source-verified bibliographic entries,
BibTeX, research-overlap notes and a reading plan. Reading depth is recorded
honestly: abstract/project-page review, not completed reproduction.

Validation: standalone regression tests and local fixture demonstrations.
No physical robot trials, live-model benchmark or performance superiority is
claimed. Automatic repair, learned applicability and the live ticos-edge adapter
remain planned. This alpha is not a production robot controller.
