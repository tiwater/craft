# Contributing

Discuss research scope in an issue; submit implementation changes by pull request.
Install `.[dev]`, run `python -m pytest` and `python -m build`.
Include regression evidence for failure/resume behavior and explicitly label
fixture, simulator, recorded-sensor and physical-robot results.
Do not submit credentials, customer orders, private endpoints or robot recordings
without redistribution rights. Keep references and novelty claims auditable.
Contributions are under the repository's Apache-2.0 license.
