# Reading and reproduction plan

## Priority 1: closest baselines

CaP-X, ASPIRE, ACE-CaP-0, RoboRepair, Reliable CaP and CodeBotler/RoboEval.
For each, record full-text sections, code commit, license, prerequisites,
observation privileges, robot API abstraction, generated artifact, feedback,
state persistence, repair scope, completion checks, budgets and held-out splits.

## Priority 2: representation, memory and cost

VoxPoser, ReKep, DROC, RoboSkill, AMP1, RoboScript (both projects), CaPtain,
Code as Policies, ProgPrompt, RoboCodeX and InCoRo.
Determine whether reuse means frozen executable code, retrieved text guidance,
a learned action policy, or repeated model invocation. These are not equivalent.

## Priority 3: adjacent experimental infrastructure

ENPIRE, RoboClaw, Voyager, Scaling Up and Distilling Down.
Study reset/recovery, data generation and skill accumulation while preserving
physical-vs-virtual and code-vs-neural-policy distinctions.
